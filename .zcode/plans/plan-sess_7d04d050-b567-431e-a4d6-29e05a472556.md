# 桌面播放器「Player」MVP 实施计划（MKV 优先版）

三个方向性问题按默认执行：**PySide6 技术栈、仅 macOS 起步（架构保持跨平台）、多语言识别模型（可配置）**。根据你的反馈，**播放内核改为 libmpv 以优先保证 MKV 支持质量**。

## 一、技术选型

| 组件 | 选型 | 理由 |
|---|---|---|
| UI 框架 | PySide6 ≥ 6.7 | pip 可装；成熟的控件与布局体系 |
| **播放内核** | **libmpv（python-mpv 绑定，render API 嵌入 QOpenGLWidget）** | **MKV 生态事实标准**（IINA/Celluloid 同内核）：HEVC/AV1/10bit、多音轨、章节、ASS/SRT 内置字幕全支持，VideoToolbox 硬解。开发期 `brew install mpv` 提供 dylib，打包时随 .app 捆绑 |
| 音频解码 | PyAV (av) | 独立解码音频轨为 16kHz 单声道 PCM 喂给语音识别，与播放管线解耦 |
| 语音识别 | faster-whisper (CTranslate2, int8) | Apple Silicon CPU 快于实时；STT 层做成接口，后续可插 sherpa-onnx/SenseVoice 中文优化后端 |
| 持久化 | JSON（QStandardPaths 应用配置目录） | 设置、播放进度、片尾标记；字幕缓存 .srt 按文件指纹存放 |
| 打包 | PyInstaller + 捆绑 libmpv.dylib | 产出可双击的 .app，消除 brew 依赖 |

## 三、功能与里程碑

**M1 播放骨架（MKV 优先）**
- 打开/拖拽文件即播；播放/暂停、进度条、音量、倍速
- MKV 特性：内置字幕轨（含 ASS 特效）自动加载渲染；多音轨切换菜单；VideoToolbox 硬解默认开启
- 快捷键：空格暂停、←/→ 快退快进 10s、↑/↓ 音量
- 记住每文件播放进度（重开续播）、窗口大小、音量

**M2 目录自动播放列表**
- 打开任一文件时扫描同级目录媒体扩展名（**mkv 优先排序** + mp4/mov/avi/webm/ts + mp3/flac/m4a/wav/ogg 等），自然排序（1,2,…,10 不是 1,10,2）
- 上/下一首、三种循环模式、播放列表面板、列表状态记忆

**M3 本地 AI 实时字幕（核心，最大风险项）**
- 字幕源策略（贴合 MKV 场景）：默认**自动模式**——文件自带字幕轨就用内置的，没有才启用 AI 生成；设置可改为"强制 AI"（此时自动隐藏内置字幕轨避免重叠）或"关闭"
- PyAV 后台解码音频 → 转写线程**领先播放位置 30–60 秒**滚动转写（30s 窗口 + 2s 重叠，Silero VAD 过滤静音），字幕按播放时钟实时显示——观感即"实时"，且比逐句流式更稳、可缓存
- seek 到未转写区域自动跳转解码位置继续转写；转写跟不上时状态栏提示可换小模型
- 结果缓存 .srt（路径+大小+修改时间指纹），二次打开秒载不耗 CPU；一键导出 .srt 到视频旁
- 设置项：AI 开关、模型（base/small/medium）、语言（自动/中文/英文）；首次使用显示模型下载进度（small/int8 约 250MB）
- AI 字幕自渲染叠层，不修改原文件

**M4 自动跳过片尾（可开关）**
- 播放时点"标记片尾"记录当前时间点；按**单文件 > 同目录**两级记忆（同季剧标记一次全目录生效）
- 设置全局开关（默认关）；到达标记点自动跳下一集（无下集则跳至结尾）；控制栏常驻手动跳过按钮兜底
- 设置中可查看/清除已标记列表

**M5 打磨与打包**
- 深色主题（Fusion + 暗色调色板）、首次使用引导文案
- PyInstaller 打包 .app（捆绑 libmpv.dylib）；README 使用说明；git init + Conventional Commits 提交历史

## 四、测试与验收
- pytest 单测：播放列表扫描/自然排序/循环模式、片尾跳过状态机（优先级/开关/边界）、字幕缓存指纹与分段查找、转写调度（注入假 STT+假时钟验证追赶/seek）、设置持久化
- pytest-qt 冒烟：主窗口初始化、打开文件流程（mock 内核）
- `make setup / lint / test / run` 可用；core 与 ai 模块覆盖率 ≥80%
- 人工验收：**MKV（含内封字幕+双音轨）直接播放正常**；无字幕 mp4 打开 30 秒内出字；连播目录片尾自动跳下一集

## 五、风险与对策
- libmpv 在 macOS 的嵌入渲染 → 采用官方推荐的 render API 方案（python-mpv 自带 Qt 示例可参考），playback.py 隔离接口，极端情况下可回退 QtMultimedia
- 模型首次下载慢/转写速度不足 → 下载进度提示；默认 small/int8 可调；缓存避免重复计算
- brew 依赖 → 打包捆绑解决，开发期写进 make setup 检查项

**依赖**：运行时 PySide6、python-mpv、av、faster-whisper、numpy（+ brew mpv 提供动态库）；开发 pytest、pytest-qt、ruff、black、isort（Python ≥ 3.11）
