# 映序

映序是一款简洁沉浸的桌面播放器，以视频播放为中心，支持本地 AI 实时字幕、目录播放列表与片尾跳过（macOS 起步）。

核心特性：

- **MKV 优先的播放内核**：基于 libmpv（IINA 同源），HEVC/AV1/10bit、多音轨、内封字幕开箱即用
- **本地 AI 实时字幕**：faster-whisper 离线转写，领先播放进度生成字幕，无需联网、不上传数据；结果缓存为 `.srt`；默认关闭，需要时一键开启
- **目录自动播放列表**：打开任一文件自动扫描同目录媒体文件并自然排序连播
- **记住每目录看到哪集**：打开目录时从上次播放的剧集继续（含播放位置）；那集已看完则自动顺延下一集
- **最近目录**：记住最近打开的目录，可在欢迎页或“文件 → 最近打开的目录”中一键打开；文件选择框也会从上次目录开始
- **AirPlay 直投**：使用 macOS 原生设备选择器，把视频发送到 AirPlay 电视；MKV 等容器会无损重封装为 MP4
- **自动跳过片尾**（可开关）：手动标记一次片尾点，按单文件/同目录两级记忆
- **观看调整**：截图、画面比例/缩放/旋转、音画同步与字幕偏移微调、AB 循环、章节导航、窗口置顶、画中画（换文件时自动重置，不跨文件保留）

## 快速开始

```bash
make setup    # 建虚拟环境、装依赖（需要 Homebrew 的 mpv 提供 libmpv）
make test     # 运行测试
make run      # 启动播放器
make package  # 打包 dist/Yingxu.app（显示名称：映序；捆绑 libmpv）
make install  # 安装并启动到 ~/Applications/Yingxu.app
```

依赖说明：`brew install mpv` 提供 libmpv 动态库；首次使用 AI 字幕会自动下载识别模型（默认 small/int8 约 250MB，之后完全离线）。

## AI 字幕工作方式

AI 字幕默认关闭，不自动转写。需要时点击控制条上的 AI 字幕按钮临时开启，或在“字幕”菜单选择启用策略：自动（无内置字幕时启用）、始终启用、关闭，所选状态会被记住。启用后，转写线程持续把播放位置之后 60 秒窗口的内容转写掉，字幕按播放时钟精确显示——观感即“实时”，且比逐句流式更稳；领先窗口无欠账后自动补全整个文件并写缓存（`.srt`，按文件指纹存放），二次打开不再耗 CPU。“自动”策略下文件自带字幕时直接用内置字幕（MKV 内封 ASS 正常渲染）。设计细节见 `docs/design.md`。

## 使用

| 操作 | 快捷键 |
|---|---|
| 打开文件 / 目录 | `Cmd+O` / `Shift+Cmd+O` |
| 播放/暂停（或单击画面） | `空格` |
| 全屏（或双击画面） | `F` / `Esc` 退出 |
| 快退/快进 10s | `←` / `→` |
| 音量 | `↑` / `↓` |
| 上一个 / 下一个 | `Cmd+[` / `Cmd+]` |
| 播放列表抽屉 | `Cmd+L` |
| 标记片尾点 | `Cmd+M` |
| 手动跳过片尾 | `Cmd+S` |
| 截图（保存到 `~/Pictures/映序`） | `S` |
| 画面比例 / 旋转 | `A` / `R` 循环切换（“播放 → 画面”可选定值） |
| 画面缩放 | `+` / `-` |
| 字幕提前 / 延后 0.1s | `Z` / `X` |
| 音频提前 / 延后 0.1s | `[` / `]` |
| AB 循环 | `L`：标记 A → 标记 B → 清除 |
| 上一章 / 下一章 | `Option+←` / `Option+→` |
| 窗口置顶 | `Cmd+T` |
| 画中画 | `Shift+Cmd+P` |

界面为全幅沉浸式：视频铺满窗口，控制元素为悬浮层，播放中鼠标静止 2.5 秒自动隐藏（悬停在控件上则保持显示）；倍速/音量变化有屏幕 OSD 提示；进度条上的淡蓝色段表示 AI 字幕已转写覆盖的范围，淡绿色段表示 AB 循环区间，细白刻度表示章节位置。画中画把窗口缩成置顶小窗（跟随源视频比例），`Esc` 或再次按快捷键退出。

AirPlay 使用 macOS AVFoundation 播放通道。MP4、M4V、MOV 可直接投屏；MKV、AVI 等会尝试无损重封装为 MP4，不重新编码视频和音频，因此重封装速度通常远快于视频时长。源文件使用电视不支持的编码时，播放器会提示失败并继续本机播放。投屏时，播放/暂停、进度、音量和倍速由播放器同步；AI 字幕和播放器选择的内置字幕不会传输到电视。

详细设计见 `docs/design.md`。

## 下载与更新

macOS Apple Silicon 版本可在 [GitHub Releases](https://github.com/huruizhi/yingxu-player/releases) 下载。下载版尚未使用 Apple Developer ID 签名和公证，首次打开时 macOS 可能显示安全确认；从源码安装可运行 `make install`，默认安装到 `~/Applications`。

播放器启动后会在后台检查 GitHub 最新正式版。发现新版本时会提示版本号并提供发布页链接；检查失败不会影响播放，也不会自动替换应用。也可从“帮助 → 检查更新”手动检查。
