# Player

简洁实用的桌面播放器（macOS 起步）。

核心特性：

- **MKV 优先的播放内核**：基于 libmpv（IINA 同源），HEVC/AV1/10bit、多音轨、内封字幕开箱即用
- **本地 AI 实时字幕**：faster-whisper 离线转写，领先播放进度生成字幕，无需联网、不上传数据；结果缓存为 `.srt`
- **目录自动播放列表**：打开任一文件自动扫描同目录媒体文件并自然排序连播
- **自动跳过片尾**（可开关）：手动标记一次片尾点，按单文件/同目录两级记忆

## 快速开始

```bash
make setup    # 建虚拟环境、装依赖（需要 Homebrew 的 mpv 提供 libmpv）
make test     # 运行测试
make run      # 启动播放器
```

依赖说明：`brew install mpv` 提供 libmpv 动态库；首次使用 AI 字幕会自动下载识别模型（默认 small/int8 约 250MB，之后离线可用）。

## 使用

| 操作 | 快捷键 |
|---|---|
| 打开文件 / 目录 | `Cmd+O` / `Shift+Cmd+O` |
| 播放/暂停 | `空格` |
| 快退/快进 10s | `←` / `→` |
| 音量 | `↑` / `↓` |
| 上一个 / 下一个 | `Cmd+[` / `Cmd+]` |
| 播放列表面板 | `Cmd+L` |
| 标记片尾点 | `Cmd+M` |
| 手动跳过片尾 | `Cmd+S` |

详细设计见 `docs/design.md`。
